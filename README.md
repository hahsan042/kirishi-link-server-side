# Overview

The KrishiLink Server is a backend API built with Node.js and Express.js, designed to power the KrishiLink agricultural marketplace.
It connects farmers and buyers, manages crops, user interests, and agricultural blog news — all stored securely in MongoDB Atlas.

# Features

🌾 Crop Management:
Add, update, delete, and fetch all crop data from MongoDB.

💬 Interest Handling:
Buyers can send interest in crops; owners can accept or reject interests.

📰 Blog/News Management:
Full CRUD API for agro news posts.

👩‍🌾 Farmer-Buyer Interaction:
Connects both parties seamlessly through interest-based requests.

🛡️ Secure Environment Configuration:
Sensitive credentials managed with .env variables.

# Technologies Used

Runtime: Node.js

Framework: Express.js

Database: MongoDB (Atlas)

Environment Variables: dotenv

Deployment: Vercel
